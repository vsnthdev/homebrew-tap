# Homebrew Tap

Personal Homebrew tap for macOS applications and tools by [@vsnthdev](https://github.com/vsnthdev).

## Installation

Install directly with a single command:

```bash
brew install --cask vsnthdev/tap/velquo
```

### Available Casks

| Cask | Description | Repository |
| --- | --- | --- |
| `velquo` | Native Apple Silicon client for KDE Connect | [vsnthdev/Velquo](https://github.com/vsnthdev/Velquo) |

## Updating & Uninstalling

```bash
brew upgrade --cask vsnthdev/tap/velquo
```

To uninstall:

```bash
brew uninstall --cask velquo
```

To remove all app data, logs, caches, and preferences as well:

```bash
brew uninstall --cask --zap velquo
```
